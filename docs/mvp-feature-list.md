# v1 MVP feature list

Maps to [v1 user journeys](user-journeys.md) (A–F).

## In scope

| Feature / screen | Purpose | Journeys |
| --- | --- | --- |
| Role intake | Start with resume + JD, JD only, or a manually entered target role | A, B, C |
| Skill gap summary | Show matches, gaps, and unclear/missing evidence for the target role | A, B, C |
| Roadmap proposal | AI proposes a learning roadmap from gaps | A, B, C |
| Roadmap review & approve | User edits or approves before a roadmap becomes active | A, B, C |
| Active roadmap view | See the current plan: topics/skills and suggested next work | D, E, F |
| Learning session log | Capture a short learning entry and attach it to skill(s) / roadmap | E, D |
| Evidence & progress | Track Studied → Practiced → Applied → Demonstrated and refresh priorities | D, E |
| Roadmap switcher | Switch between independent roadmaps without mixing progress | F |

## Suggested build order

1. Role intake  
2. Skill gap summary  
3. Roadmap proposal + review & approve  
4. Active roadmap view  
5. Learning session log  
6. Evidence & progress  
7. Roadmap switcher  

## Out of scope for v1

- Other professions beyond software engineering  
- Automatic import from every learning site  
- Job application tracker / LinkedIn posting  
- Polished design system / marketing site  
- Multi-user teams / org admin  
- Paid cloud LLMs as the required default (prefer free/local when AI is added)
